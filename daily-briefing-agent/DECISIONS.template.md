## 2. 关键设计决策

> 围绕以下几个问题展开，不必全部回答，但回答的要说清原因。

- **拆分**：你的 Agent 是单步 prompt 还是多步？用了哪些角色 / 工具？
- **筛选与排序**：30 条新闻 + 20 封邮件 + 11 个日程，怎么挑出进入简报的内容？
- **去重**：当邮件和新闻讲同一件事（例：PSD3）时怎么处理？
- **profile 落地**：你怎么把用户偏好真正注入到生成过程？仅靠 prompt 还是有显式过滤？
- **时长控制**：怎么保证 60–90 秒？是事后裁剪还是事前规划？
- **TTS 友好度**：数字、URL、专有名词是怎么口语化的？
- **可观测性 / 调试**：当某条信息没出现在简报里时，你能解释为什么吗？
